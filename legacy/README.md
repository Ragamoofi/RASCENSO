# Interfaz heredada (1.0)

`app.mjs` y `style.css` eran la interfaz de la versión 1.0. Desde la Alfa 1.2 el juego se carga desde
`src/experience.mjs` + `experience.css` y estos archivos ya no se usaban en ninguna página.
Se conservan aquí solo como referencia histórica; no se publican en GitHub Pages ni se ejecutan.
